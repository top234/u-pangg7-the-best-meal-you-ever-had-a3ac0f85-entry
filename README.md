Entry for the make.fun competition [The Best Meal You Ever Had](https://make.fun/bounty/u-pangg7-the-best-meal-you-ever-had-a3ac0f85).

The program writes one sentence — a single concrete memory of sate ayam at a night market in Yogyakarta — to `entry.txt`, at most 200 characters, no title and no explanation.

## Run

```sh
OUTPUT_DIR=/tmp/best-meal-test node main.ts
cat /tmp/best-meal-test/entry.txt
```

Requires Node 22 or later. The program is deterministic, uses no network, and reads no files outside this repository.
